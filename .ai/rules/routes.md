# Routes

## Страницы: только / фиксирован, остальные — catch-all
Единственный фиксированный страничный роут — `/` (PageController::index, slug `index`). Все DB-страницы обслуживает catch-all `/{slug}` / `/{locale}/{slug}`: нет опубликованной страницы/черновика/перевода → 404, fallback на прототип удалён. Новые хардкод-роуты для DB-страниц не заводить; ссылки в прототипах — `url('/slug')`, не route()-имена (имён страницных роутов больше нет). Роуты неконвертированных прототипов (catalog, about, …) — временные, до конвертации в блоки.

## Страницы динамические: DB + catch-all, фиксированы только / и POST-обработчики
Все контентные страницы — DB-страницы из админки MoonShine (slug + переводы + flexible-блоки), обслуживаются catch-all /{slug} и /{locale}/{slug}. Фиксированный страничный GET-роут один — /. Новую страницу не заводить хардкод-роутом: класс блока + вью + идемпотентный сидер, catch-all подхватит сам. Ссылки на страницы — url('/slug'), не route()-имена. Допустимые фиксированные роуты — только служебные неконтентные (cart, checkout, profile) и POST-обработчик формы контактов (валидация; отправка в CRM — закомментированный пример, без почты); хранение заявок — во внешней CRM.
