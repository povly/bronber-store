# Routes

## Страницы: только / фиксирован, остальные — catch-all
Единственный фиксированный страничный роут — `/` (PageController::index, slug `index`). Все DB-страницы обслуживает catch-all `/{slug}` / `/{locale}/{slug}`: нет опубликованной страницы/черновика/перевода → 404, fallback на прототип удалён. Новые хардкод-роуты для DB-страниц не заводить; ссылки в прототипах — `url('/slug')`, не route()-имена (имён страницных роутов больше нет). Роуты неконвертированных прототипов (catalog, about, …) — временные, до конвертации в блоки.
