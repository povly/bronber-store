# Адаптивный аккордеон для секции «Наша история» на странице about (< 1200px)

**Date:** 2026-08-07 12:08
**Files:** resources/views/blocks/about/about.blade.php, resources/css/blocks/about/style.css, resources/js/blocks/about/index.js
**Severity:** low

## Problem

На странице `about` секция истории компании (2017–2021) на всех брейкпоинтах
отображалась одинаково: горизонтальный слайдер годов + одна панель контента снизу.
По макету Figma на телефоне и планшете (< 1200px) должен быть вертикальный
аккордеон — каждая строка «YYYY — Заголовок» с шевроном, разделители 1px,
раскрытый пункт показывает текст + картинку инлайн. Десктоп (≥ 1200px) — без изменений.

## Root Cause

Раскладка не была разделена по брейкпоинтам. Единственный шаблон (слайдер + панели)
применялся ко всем ширинам. Для мобильного аккордеона нужна принципиально иная
DOM-структура (вертикальный список кликабельных заголовков с inline-контентом),
которую невозможно получить чистой CSS-трансформацией из горизонтального слайдера
на transform.

## Solution

Добавлена вторая раскладка рядом с существующей, переключение через CSS @media
(паттерн уже используется в `mobile-nav`):

- **Blade:** существующий блок (слайдер + сепаратор + панели) обёрнут в
  `.about__desktop`; добавлен `.about__accordion` — цикл по тем же данным
  `$timeline`, каждый пункт: `<button>` заголовок «YYYY — Title» + шеврон SVG,
  контент с `x-show="accActive === N" x-collapse`, сепараторы между пунктами.
- **CSS (mobile-first):** `.about__desktop { display: none }` по умолчанию,
  `.about__accordion { display: block }`. На `min-width: 1200px` — наоборот.
  Стили аккордеона используют `fluid-type()` по конвенции проекта.
- **Alpine JS:** `about()` расширен свойством `accActive: 0` и методом
  `accToggle(i)` (toggle: повторный клик по открытому закрывает, `accActive = -1`).
- Классы `.about__text`, `.about__image-wrap`, `.about__image` переиспользованы
  в контенте аккордеона — дублирования CSS нет. Дублирование DOM-изображений
  безопасно: vanilla-lazyload не грузит картинки из `display:none`-контейнеров.

## Prevention

- Когда требуется принципиально разная раскладка на разных брейкпоинтах
  (не просто ресайз элементов) — используйте два блока с CSS `display`-переключением,
  а не пытайтесь трансформировать одну структуру.
- Канонический брейкпоинт десктопа в этом проекте — `min-width: 1200px`.
  Проверяйте границу именно на 1199/1200.
- Расширяйте существующий Alpine-компонент (`Alpine.data('about', ...)`),
  не создавайте новый для той же секции.
- Верифицируйте адаптив через DOM-state (`getComputedStyle().display` + classList),
  когда визуальный скриншот недоступен — это точнее для структурных изменений.
